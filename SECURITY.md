# Security

How the system keeps each person to what they may read, and what shows it, is in [docs/security.md](docs/security.md).

## Reporting a problem

If you find a way to get anything from a document you may not read, or anything else that looks like a security problem, please tell me privately rather than in a public issue: through GitHub's private vulnerability reporting on this repository if it is enabled, or by contacting me directly through my GitHub profile.

Helpful to include:

- what you did, as requests or steps I can repeat;
- who you were signed in as, and what you got back that you shouldn't have;
- the request ID from the response (the `X-Request-ID` header, or `request_id` in an error), which finds the request in the log and the audit trail.

The company in this repository, AcmeCorp, and every document and person in it, is fictional. Testing against the public demo spends a shared model budget and nothing else; please don't run floods or scanners against it.

This is a portfolio project, maintained by one person. I'll reply as soon as I can, but there is no support agreement or response time.
